# Synapse

Synapse helps people in Bucharest find the right private doctor. It puts doctors from four private
networks side by side — specialty, real consultation price, professional rank, distance and CNAS
coverage — and includes **Synapse Assistant**, a chatbot that suggests which *type* of specialist fits
the symptoms someone describes. Booking always happens directly with the clinic.

Built for the VNU hackathon. (Synapse was formerly called MedIndex; some internal identifiers such as
`window.MedIndex`, `medindex.*` storage keys and the `X-Requested-With: MedIndex` header keep the old name.)

## Two ways to run it

### 1. Static, browse-only demo (GitHub Pages)

The site is plain HTML/CSS/JS with no build step, so it can be hosted as static files
(for example `https://<user>.github.io/<repo>/`). In this mode:

- the doctor directory, filters, sorting and distance work;
- the assistant runs in **rule mode** (local rules in the browser, nothing is sent anywhere),
  including the red-flag check that shows the **112** emergency banner;
- accounts, reviews, Premium and the AI (Kimi) assistant are switched off, and the pages say so:
  *"This public demo runs in browse-only mode: accounts, reviews, Premium and the AI assistant need the Synapse server."*

How the page decides: `js/config.js` sets `window.SYNAPSE_CONFIG = { backend: "auto" }`.
On `*.github.io`, or with `backend: "off"`, no API request is made at all. Otherwise the page probes
`GET /api/me` once; a 404, a non-JSON answer or a network error means browse-only mode.
The repo contains `.nojekyll` and a `404.html` for Pages.

### 2. Full app (local server)

```sh
python3 server/proxy.py        # from the repo root, Python 3 standard library only
```

Open **http://127.0.0.1:8000**. This adds sign-up/login, doctor reviews, a demo Premium plan,
a metadata-only Secure Medical Cloud, saved chats and the AI assistant. See `server/README.md`.

For AI mode, put your Moonshot (Kimi) key in a `.env` file in the repo root:

```sh
MOONSHOT_API_KEY=your-key-here
```

**Never commit `.env`** (it is in `.gitignore`). Without a key the assistant falls back to its rules.

Opening `index.html` directly from disk (`file://`) also works for browsing; the pages then explain how
to start the local server.

## Data sources and real-data rules

`data/doctors.js` is generated by `scraper/scrape.py` from the public web pages of **Sanador, MedLife,
Regina Maria and Medicover** (227 doctors in the current build). Each record keeps the source URL of its
price and the date it was collected.

- **No invented data.** A field that cannot be read from the source stays empty; a record without a valid
  price is dropped, never guessed. No ratings or reviews are seeded — reviews only come from real users
  of the local server.
- Scraping respects `robots.txt` and uses a local cache (`scraper/cache/`, not committed).
- Prices change: always confirm with the clinic before booking.

## About the AI — important

Synapse Assistant gives **general health information, not a diagnosis**, and its advice may be wrong.
It never replaces a doctor. Emergency signs (for example chest pain with breathlessness, or
"nu pot respira" / "I can't breathe") are detected in the browser first and show a red banner:
**in an emergency, call 112.** In AI mode the conversation is sent to an AI service (Kimi, via the local
proxy); its replies are filtered so they never contain invented phone numbers, prices or doctor names.

## Project layout

| Path | What |
| --- | --- |
| `index.html`, `doctors.html`, `premium.html`, `account.html`, `cloud.html` | the five pages |
| `js/` | shell (i18n EN/RO, header, API client, config), page scripts |
